# 🐍 Python Fundamentals

This repository contains my learning and practice work on the **basic fundamentals of Python**.

Whether you are a beginner or revisiting Python basics, this repo can be a helpful reference.

- Python syntax & keywords

- Conditional statements (`if`, `elif`, `else`)  
- Loops (`for`, `while`)  
- Functions  
- Lists, Tuples, Sets, and Dictionaries  
- String operations  
- Basic problem-solving programs
